STEP 1: OPEN TWO TERMINALS
═══════════════════════════════════════════════════════════════════════════════

   ┌─ TERMINAL 1 ─────────────────────────────────────────────────────┐
   │                    (Data Collector)                              │
   │  Runs TFLogger node and collects data in deques                  │
   └─────────────────────────────────────────────────────────────────┘

   ┌─ TERMINAL 2 ─────────────────────────────────────────────────────┐
   │                    (Data Accessor)                               │
   │  Accesses deques and exports to CSV/Pickle files                 │
   └─────────────────────────────────────────────────────────────────┘


STEP 2: TERMINAL 1 - RUN DATA COLLECTOR
═══════════════════════════════════════════════════════════════════════════════

Copy and paste this command (one line):

  ros2 run my_tf_logger demo_base_log --ros-args \
    -p parent_frame:=camera \
    -p child_frame:=object_1 \
    -p intermediate_frame:=object_2 \
    -p goal_frame:=object_3 \
    -p rate_hz:=10.0 \
    -p bridge_pose_file:=/home/arka/unitree_sdk2/live_bridge/draft_demo_robot_pose.txt

Expected output:
  ✅ [INFO] Logging TF 'camera_frame' -> 'object' at 10.0 Hz using deques
  ✅ [INFO] Deques initialized for camera->object1, object2, object3, base_link

Leave this terminal RUNNING!


STEP 3: TERMINAL 2 - RUN DATA ACCESSOR
═══════════════════════════════════════════════════════════════════════════════

Copy and paste:

  python3 /home/arka/Desktop/ros2_ws/src/my_tf_logger/my_tf_logger/access_deque_data.py

This will automatically:
  ✅ Collect data for 10 seconds
  ✅ Print deque summaries to terminal
  ✅ Show latest readings
  ✅ Calculate error statistics
  ✅ Export to CSV files (open in Excel!)
  ✅ Export to Pickle files (use in Python!)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

  ❌ Error: "camera_frame" not available
     ✅ Solution: Make sure TF frames are being published to your system

  ❌ Error: No data collected
     ✅ Solution: 
        1. Keep Terminal 1 RUNNING
        2. Wait 2-3 seconds for connection
        3. Run Terminal 2 command again

  ❌ Error: Permission denied
     ✅ Solution: chmod +x /path/to/access_deque_data.py

  ❌ Want longer collection time?
     ✅ Solution: Edit access_deque_data.py line:
        accessor.start_collection(duration_seconds=30)  # Change to 30, 60, etc


KEY POINTS
═══════════════════════════════════════════════════════════════════════════════

  ✅ NO MORE TEXT FILES - Use structured CSV/Pickle instead
  ✅ NO MORE FILE CORRUPTION - Data stored reliably in memory
  ✅ NO MORE MANUAL PARSING - Get structured dictionaries
  ✅ AUTOMATIC ERROR TRACKING - Translation, rotation, RPY errors calculated
  ✅ EASY EXPORT - CSV for Excel, Pickle for Python analysis
